# Security policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please do not open a public issue. Email **srgsf.github@gmail.com** with:

- what you found and the affected version,
- steps or a proof of concept to reproduce it,
- the impact as you see it.

You will get an acknowledgement within a few days. Once a fix is released the report can be
published, with credit if you want it.

## Scope

adsvc handles user tokens, signed records from other nodes, and untrusted media bytes.
Reports on authentication, the `/sync/*` replication endpoints, the web page, the container
parsers or the proxy's upstream handling are especially welcome.
