# Logo

- `logo.webp`: the logo (1254×1254). `web/static/img/logo-80.png` (admin header) and
  `logo-256.png` (login page) are scaled from it.
- `header.svg`: the README's header: the logo (a 240 px JPEG, embedded, since GitHub does
  not load images referenced from an SVG), the name and the tagline. The text follows the
  reader's light or dark scheme.
- `icon.webp`: the fingerprint alone, the source of the browser icons
  (`web/static/img/favicon-16.png`, `favicon-32.png`, `icon-180.png`). Those use the centre
  880×880 px, 8 px above centre, with corners rounded at 20% of the side, so the print
  stays readable at 16–32 px.
