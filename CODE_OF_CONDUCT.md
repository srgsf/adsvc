# Code of conduct

We want this project to be a respectful, harassment-free place for everyone.

**Expected:** be kind and patient, assume good faith, give and accept constructive feedback,
and focus on what is best for the project.

**Not acceptable:** harassment, insults, personal attacks, discrimination, publishing
someone's private information, or other conduct that would be inappropriate in a professional
setting.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and
may ban people who repeat it.

This applies in the repository and wherever someone represents the project. To report a
problem, email **srgsf.github@gmail.com**; reports are kept confidential.

Adapted from the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/).
